### What the first look at the data showed
- AAPL 5y: 1,255 rows (2021-11-15 → 2026-11-13), no nulls, no duplicate dates, `high >= low` and `price > 0` everywhere.
- **`Close` from yfinance is already split-adjusted, even with `auto_adjust=False`.** 2020-08-28 shows $124.81, not the real ~$499 (4:1 split on 2020-08-31). Only the dividend adjustment is turned off.
- **Yahoo restates history.** `Adj Close` for old dates changes after every dividend, and `Close` after every split. Re-pulling the same date can return different numbers.
- `yf.download` returns 2-level columns `(Price, Ticker)` even for one ticker.
- Prices are indexed by plain date; splits/dividends by tz-aware timestamps (`09:30 America/New_York`) and always return the full history.
- S&P 500 list has 503 symbols (share classes like GOOGL/GOOG). `BRK.B` / `BF.B` must become `BRK-B` / `BF-B` for Yahoo.
