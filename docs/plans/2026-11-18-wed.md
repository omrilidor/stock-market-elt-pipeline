### Decisions made (Wed morning)
1. **FRED series:** `DGS10` (10y Treasury, daily), `DFF` (Fed funds, daily), `VIXCLS` (VIX, daily), `CPIAUCSL` (CPI, monthly), `UNRATE` (unemployment, monthly). Mixed frequencies, so the daily/monthly join happens in dbt.
2. **FRED raw format:** one JSON file per series, the API response saved unchanged (`data/raw/fred/<run_date>/<SERIES>.json`). Pure ELT; files are only KBs.
3. **Volume layout:** `/Volumes/workspace/stock_market/raw/<source>/<run_date>/<file>`, mirroring local `data/raw/`.
4. **Upload:** `extract/upload_raw.py`, new dependency `databricks-sdk==0.167.*`, on a separate branch `feature/upload-to-volume` (one topic per PR).
5. **Re-running a run date replaces the whole folder** (same as SEC). One run folder = exactly one run's output. A `--series` subset on an existing date drops the other series, so use another `--run-date`/`--out` for partial pulls.
